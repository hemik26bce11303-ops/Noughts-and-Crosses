# Noughts-and-Crosses
I built a Noughts and Crosses (Tic‑Tac‑Toe) game in Python. Noughts and Crosses runs in the command line, which offers smooth input validation, a pleasant user experience and no external dependencies.

✨ Features

Classic Gameplay- Experience the Noughts and Crosses strategy directly in your terminal.

Two Player Mode- Compete locally with a friend, Player X, against Player O.

Robust Input Validation- Handles entries, out of range moves and occupied spaces automatically keeping the game crash‑free.

Zero Dependencies- Built entirely in Python—no installation steps or third‑party libraries needed.

⚒️ Steps to Run the Program.
1. Prerequisite: Ensure Python 3.x is installed on your system.

2. Save the Code: Save the provided source code in a file named main.py.

3. Open Terminal: Open your command prompt (Windows) or terminal (Mac/Linux) and navigate to the folder where main.py is saved.

4. Execute the Script: Run the following command: python main.py
